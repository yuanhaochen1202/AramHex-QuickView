二、核对方法与来源

清单结合实际发行包内的 Python 模块、动态库版本、随包元数据和上游
构建固定版本记录，不仅根据 requirements 列名。依赖库和模型未被
本定制版改写。部分没有内嵌版本常量的模块以原构建锁定版本及分发包
元数据对应，不代表对每个上游二进制进行了可复现构建认证。

Components/ 下每个 SOURCE.json 给出组件版本、官方 PyPI 元数据、
wheel 地址、取得的许可成员和 SHA-256。为减少下载量，只读取了所需
ZIP 成员的 HTTPS 字节范围，成员 CRC 经核验；没有下载完整大 wheel，
因此没有声称已验证它的整包 SHA-256。PyPI 提供的整包校验值保留作
参考。RapidOCR wheel 没有许可成员，已从官方 v3.9.2 源码补齐全文。
Python 许可来自相同版本的 Windows 运行时；OpenSSL 许可和作者表
来自官方 openssl-3.5.9 标签。Qt 目录另行记录自己的取证方法。

SOURCE-ARCHIVES.json 提供可用的官方精确版本 Python 源码分发地址；
它不表示源代码归档已包含在本软件包中。Qt/README.txt 和 Shapely
目录的 GEOS-SOURCE.txt 另列其底层库源码和替换方式。此发行版不增加
禁止按相关许可证修改、调试、反向工程或替换这些库的限制。

审计，也不把项目层面的署名声明当作独立授予全部游戏美术资源权利。

更新任一依赖、模型或打包方式时，必须同步复核对应实际制品、完整
