GEOS bundled with Shapely 2.2.0

The shipped Windows dynamic libraries identify GEOS 3.14.1,
C API 1.20.5 (version string 3.14.1-CAPI-1.20.5).
The GEOS library has not been modified by this custom AramHex distribution.

The full GNU LGPL version 2.1 text and GEOS attribution are in:
shapely-2.2.0.dist-info/licenses/LICENSE_GEOS

GEOS source code and build instructions are published by its maintainers at:
https://libgeos.org/usage/download/
Select the 3.14.1 source release to match these libraries.
The official source repository is:
https://github.com/libgeos/geos

The application loads GEOS from separate shared libraries under
_internal/Shapely.libs/. Users may rebuild and replace them with compatible
modified libraries; no license term added by this distribution prohibits
modification, reverse engineering for debugging those modifications, or
replacement as permitted by the LGPL. Matching architecture and C ABI are
required. Keep a backup and use an isolated application copy for this work.
Accepting a later application update can restore the published libraries.

This file records the upstream source location, not a locally included source
archive or an independently verified reproduction of the vendor's build.
