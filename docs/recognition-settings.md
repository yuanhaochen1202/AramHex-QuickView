# 识别参数

这些默认值定义在 `lolhex/config.py` 的 `Settings` 中。用户版读取本地设置，远程配置中的 `settings` 字段会被过滤。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `recheck_seconds` | 5 秒 | 画面相同时，逐列复查已显示卡片的间隔 |
| `pending_seconds` | 0.9 秒 | 新读数尚待确认时，继续显示原标签的等待时间 |
| `low_match_reads` | 3 批 | 连续低匹配的 OCR 读数达到这一数量后，清除内部稳定卡组 |
| `active_hold_s` | 5 秒 | 三选一关闭后继续快速扫描的时长，0 表示立即退出快扫 |

识别线程在每轮扫描前读取当前参数。引擎连续三次读空后关闭标签；这与识别器清除内部稳定卡组是两个独立条件。
