# <img src="lolhex/ui/icon.png" alt="" width="36" height="36"> AramHex-QuickView · 海克斯大乱斗助手

这是英雄联盟「海克斯大乱斗」的 Windows 桌面助手。当前用户版 **1.1.5.8** 由 **yuanhaochen1202** 基于 **czgreat 的 AramHex 1.1.5** 定制。它沿用原项目的英雄与海克斯统计、出装和加点参考，改进了选人倒计时和海克斯刷新时的识别，并在加载画面给双方英雄逐张标出胜率。[原项目](https://github.com/czgreat/aramhex) · [原项目官网](https://aramhex.com)

- **数据库继续跟随原作者更新。** 英雄和海克斯胜率、装备参考以及游戏资料仍从原项目的数据渠道更新。可以在助手内手动检查数据更新。
- **程序只接收 yuanhaochen1202 发布并签名的用户版更新。** 助手每次启动检查一次，先验证版本清单的签名。发现新版时会弹窗询问，你同意后才下载发生变化的文件，核对文件哈希后安装。选择取消或关闭弹窗即可继续用现有版本。程序运行期间不会定时检查，也不会安装原项目的程序包。

## 下载与使用

1. 打开发行页，在 **Assets** 中下载 `AramHex-Portable-1.1.5.8-user.zip`。[下载用户版](https://github.com/yuanhaochen1202/AramHex-QuickView/releases/latest)
2. 完整解压 ZIP，在解压出的 `AramHex` 文件夹内双击 `AramHex.exe`。便携版无需安装 Python，设置和缓存保存在程序旁的 `userdata` 文件夹。
3. 在《英雄联盟》的视频设置中选择**无边框**或**窗口化**，将游戏或选人窗口切到前台。切换到其他应用时，助手会暂停画面识别并隐藏游戏浮层。

适用于 Windows 10/11 64 位。选人和海克斯识别默认兼容简体和繁体中文，英文、日文客户端可在助手设置中选择相应语言。加载页标签按国服画面校准，其他客户端布局仍需实测。

## 这版在一局游戏里改了什么

### 选人倒计时

看到「选择你的英雄」后，助手优先读取随机英雄卡上的称号。几张卡淡入的速度可能不同，先认出哪张，就先在那张卡上显示胜率，其余位置短间隔重试。例如前两张已经清晰、第三张还在淡入时，可以先看前两张的数字。等这组候选识别完整，再给其中胜率最高的英雄加金框。

对画面稳定的小区域，助手复用已确认的识别结果。读不出的文字会重试，必要时扩大识别区域。慢扫描返回后会重新核对窗口和卡组，避免把上一组的数字贴到新卡上。

### 首次海克斯与刷新

三选一首次出现时，助手先读取三张卡的标题，结合当前英雄查询各选项的统计。标题位置偏移或难以辨认时，后台会扩大搜索区域，前台继续读取标题。刷新某一栏后，即使旧扫描较晚才结束，也会重新比对眼前的卡面，丢弃已换掉的选项，避免在新海克斯上显示上一张的分数。

### 加载时看双方英雄胜率

助手从当前游戏进程对应的本局日志读取英雄名单，再逐张读取加载画面上的**英雄名称或称号**，核对上下排和卡位。名单可以分批到达，确认一张便在对应名称上方显示大号百分比。某些皮肤名难以辨认时，只有同排多个英雄与日志位置一致、画面稳定且顺序没有冲突，才补齐该排。未确认卡位时留空，已确认英雄但统计库缺数据时显示「暂无数据」。

百分比表示该英雄在**已采集的海克斯大乱斗样本**中的胜率。助手不查询这张卡对应玩家的个人胜率，也不计算本局胜负概率。支持海克斯大乱斗正式匹配，以及已核对模式编号和自定义标记的海克斯自定义对局。

### 补全自己的英雄

如果选人时没认出最终使用的英雄，助手可根据本局日志里的本机英雄标记，补全后续海克斯推荐和出装参考。已有的手选或画面识别结果优先。进入下一局时，助手会清除上一局的日志识别结果。

## 统计、隐私与实测范围

- **数据来源。** 英雄与海克斯胜率、命运之武器的装备参考来自原作者采集的对局。统计库提供细分时可选择娱乐、中分、前 5%，缺少对应数据时按全体样本展示。英雄、海克斯、装备的名称与图标，以及出装、技能加点资料来自官方公开数据。[统计数据仓库](https://github.com/czgreat/aramhex-data) · [在线查询](https://aramhex.com/data/)
- **读取范围。** 选人和海克斯依靠屏幕文字与图像。加载时只用进程路径、启动时间定位本局游戏日志，再用本机客户端日志核对同局模式。助手不连接游戏客户端接口，不读取进程内存，不注入游戏或模拟按键。
- **隐私。** 本版已移除匿名安装编号、使用统计和诊断日志上传。日常排错日志保存在本机，自己开启调试时可能产生详细日志和截图。联网更新会向服务端请求文件。若使用可选查分，查分服务会收到你填写的「名字#编号」，之后助手可用已保存的名字复查分段。[隐私声明](PRIVACY.md)
- **验证范围。** 1.1.5.8 已验证便携包正常启动、界面与文字识别自检，以及从 1.1.5.7 到 1.1.5.8 的隔离增量安装。加载标签做过实图回放，覆盖 16:9 画面的多个分辨率及双方上下排交换。新版本在其他电脑、新实战对局、超宽屏和少人自定义实际布局上的表现仍待验证。标签出现时间取决于游戏日志何时写入以及文字何时清晰可读。

需要本机排错时，可在 `AramHex.exe` 旁创建空文件 `debug.txt`，从托盘退出助手后重开，在 `userdata/aramhex.log` 查看记录。删除标记并重启即可关闭详细记录。

## 从源码运行或构建

公开源码适用于 Windows 10/11 64 位和 64 位 Python 3.13。在仓库根目录打开 PowerShell，执行以下命令即可启动助手。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -c packaging/constraints.txt -r requirements.txt
.\.venv\Scripts\python.exe -m lolhex
```

如需自行生成用户版便携包，安装 PowerShell 7 后运行以下命令。生成的 ZIP 位于 `build/release/user/`。[开发说明](docs/DEVELOPMENT.md)

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
pwsh -NoProfile -File packaging/build.ps1 -Channel user -PortableOnly
```
